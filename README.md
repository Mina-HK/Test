# 暖暖英语 30 分钟学习 MVP

一个面向零基础英语学习者的纯前端网页 MVP。当前版本使用 HTML、CSS、JavaScript 和浏览器 `localStorage`，无需安装框架或后端服务。

## 文件结构

```text
.
├── index.html   # 页面结构：Dashboard、单词、语法、口语、打卡
├── styles.css   # 响应式视觉样式与组件样式
├── app.js       # 学习数据、localStorage 状态、交互逻辑
└── README.md    # 本地打开方式与后续升级方向
```

## 本地打开方式

### 方式一：直接打开

在文件管理器中双击 `index.html`，或把它拖到浏览器窗口中即可运行。

### 方式二：启动本地静态服务

如果你已经安装 Python，可以在项目根目录运行：

```bash
python3 -m http.server 4173
```

然后在浏览器打开：

```text
http://127.0.0.1:4173/index.html
```

## 当前功能

- Dashboard：显示今日任务、学习进度、连续打卡天数、认识单词数和待复习数。
- 单词模块：每天 10 个基础单词，支持标记“认识 / 不认识 / 复习”。
- 语法模块：用通俗中文解释 be 动词、一般现在时、简单疑问句。
- 口语模块：提供日常句子，点击显示中文解释。
- 打卡模块：完成后点击“今日已完成”，连续打卡天数会保存在浏览器中。
- 数据存储：所有状态保存在浏览器 `localStorage`。
- 响应式布局：适配手机与电脑。

## 下一步可以升级的功能

1. 增加每日学习计划：按日期自动切换单词、语法和口语内容。
2. 增加发音音频：为单词和句子添加真人发音或 TTS。
3. 增加复习系统：根据“不认识”的单词生成复习清单和间隔复习提醒。
4. 增加口语录音：让用户录音并对比标准发音。
5. 增加简单测验：单词选择题、填空题、听音选词。
6. 增加数据导出：把学习记录导出为 JSON，方便以后迁移到后端。
7. 升级为 React：把 Dashboard、单词卡片、语法卡片、口语卡片拆成组件。
8. 增加账号系统：未来支持跨设备同步学习进度。
